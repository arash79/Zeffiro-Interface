\section{Lead field construction}\label{sec:lead-field-construction}

A lead field is the linear map from sources in the brain (or other active
tissue) to sensors. Zeffiro stores it as \ccode{zef.L}: rows are sensors,
columns are source degrees of freedom. Inverse methods solve
\(y \approx Lx\) and never assemble \(L\) themselves.

The live dispatcher is \ccode{zef\_lead\_field\_matrix} in
\ccode{src/forward/lead\_field}. From the Mesh tool, pick a row in the
forward-simulation table (CSV
\ccode{profile/<name>/zeffiro\_forward\_simulation.ini}) and click
\textbf{Run script}. That evaluates the Script cell (for example
\ccode{zef\_eeg\_lead\_field\_isotropic;}). There is no live
\textbf{make\_all} button; the \ccode{zef\_*\_make\_all} scripts still exist
as one-shot MATLAB helpers.

\begin{lstlisting}[style=unnumberedlines, language=Matlab]
zef = zef_eeg_lead_field_isotropic(zef);   % type 1, Mesh-tool Script
% or, after setting zef.lead_field_type yourself:
zef = zef_lead_field_matrix(zef);
\end{lstlisting}

\textbf{Before.} A labelled tetrahedral mesh and \ccode{zef.sigma}, plus
\ccode{zef.sensors}. \textbf{After.} \ccode{zef.L},
\ccode{source\_positions}, \ccode{source\_directions}. If
\ccode{source\_interpolation\_on} is true (Mesh tool \textbf{LF source
interp.}), \ccode{zef\_source\_interpolation} fills
\ccode{source\_interpolation\_ind}, which inverse plugins require.

\subsection{Modality types}

\ccode{zef\_lead\_field\_matrix} switches on \ccode{zef.lead\_field\_type}:

\begin{tabularx}{\linewidth}{rX}
\(1\) & EEG, isotropic \(\sigma\) column 1, \ccode{zef\_lead\_field\_eeg\_fem} \\
\(2\) & MEG magnetometers, isotropic, \ccode{zef\_lead\_field\_meg\_fem} \\
\(3\) & MEG gradiometers, isotropic, \ccode{zef\_lead\_field\_meg\_grad\_fem} \\
\(4\) & EIT, isotropic, \ccode{zef\_lead\_field\_eit\_fem} \\
\(5\) & TES / tES, isotropic, \ccode{zef\_lead\_field\_tes\_fem} \\
\(6\)--\(10\) & Same five modalities with anisotropic \(\sigma(:,3{:}8)\) \\
\end{tabularx}

Gravity lead fields (asteroid profiles) bypass this integer dispatcher.

EEG/EIT/TES assemble a sparse stiffness \(A\), couple electrodes
(\ccode{zef\_build\_electrodes}), PCG-solve the transfer with
\ccode{zef\_transfer\_matrix} (EEG/TES) or an inlined copy (EIT), then
form \(L\) from interpolation \(G\) or, for TES, from
\ccode{zef\_tetra\_gradient\_field}. Nodes must already be in metres inside
those FEM cores; the wrappers convert using \ccode{location\_unit}.

The FEM \ccode{electrodes} argument is not the same array as
\ccode{zef.sensors}. Session sensors are \(N\times 3\) (PEM, \(xyz\)) or
\(N\times 6\) (CEM: \(xyz\), radii, impedance). After
\ccode{zef\_attach\_sensors\_volume}, PEM becomes snapped \(xyz\) which the
dispatcher divides by 1000 (mm\(\to\)m). CEM becomes a four-column
\textbf{index} table \([e, n_1, n_2, n_3]\) and is \emph{not} divided by
1000. The FEM then treats three columns as PEM and four columns as CEM.
Impedance for CEM is copied from \ccode{zef.sensors(:,6)} into
\ccode{lf\_param.impedances}.

DTI conductivity (\textbf{Forward tools \(\to\) DTI Conductivity Tool})
writes the six-column tensor used by types \(6\)--\(10\). It does not write
\ccode{zef.L}.

\subsection{Fields of \code{zef} needed by the lead field routines}%
\label{ssec:leadfield-fields}

\zeffield{nodes}{:,3}{double}{}{Volume-mesh vertices after Create FEM mesh.
FEM cores expect metres; wrappers convert from \ccode{location\_unit}.}

\zeffield{tetra}{:,4}{double}{}{Tetrahedra (1-based vertex indices), same
length as \ccode{domain\_labels}.}

\zeffield{sigma}{size(tetra,1), :}{double}{}{Conductivity. Column 1 is
isotropic \(\sigma\) (S/m). Types \(6\)--\(10\) read columns \(3{:}8\) as
the packed tensor \(xx,yy,zz,xy,xz,yz\). DTI Apply to Mesh fills those
columns.}

\zeffield{sensors}{:,3 or 6}{double}{}{Sensor geometry in the mesh frame.
PEM: \(N\times 3\) positions. CEM import (\ccode{core.io.electrodes}) is
\(N\times 6\) (\(xyz\), inner radius, outer radius, impedance in ohms).
This is \emph{not} what the FEM cores receive. After attachment, EEG/EIT/TES
see PEM as snapped \(xyz\) in metres, or CEM as an index table with 4
columns \([e, n_1, n_2, n_3]\).}

\zeffield{lead\_field\_type}{1,1}{double}{}{Integer \(1\)--\(10\) as in the
table above. Gravity scripts set a separate \ccode{gravity\_field\_type}.}

\zeffield{imaging\_method}{1,1}{double}{}{Sensor family used while
processing meshes: \(1\) EEG (optional CEM patch via
\ccode{create\_patch\_sensor}), \(2\) MEG magnetometer directions,
\(3\) MEG gradiometer (may use six direction columns).}

\zeffield{source\_model}{1,1}{ZefSourceModel}{}{\ccode{core.types.ZefSourceModel}:
Whitney / ContinuousWhitney, Hdiv / ContinuousHdiv, StVenant /
ContinuousStVenant. Interpolation \(G\) is built in
\ccode{zef\_whitney\_interpolation}, \ccode{zef\_hdiv\_interpolation}, or
\ccode{zef\_st\_venant\_interpolation}.}

\zeffield{optimization\_system\_type}{1,:}{char}{}{\ccode{'pbo'}
(position-based optimization) or \ccode{'mpo'} (mean position and
orientation) for Whitney/H(div) interpolation.}

\zeffield{source\_direction\_mode}{1,1}{double}{}{Mesh tool
\textbf{Directions}: \(1\) Cartesian, \(2\) Normal, \(3\) Basis. Controls
how columns of \(L\) are interpreted in inverse and visualization, not
which FEM file is called.}

\zeffield{n\_sources}{1,1}{double}{}{Requested source count (default
\(10000\)). The mesh may not be fine enough to place that many; the actual
count is \ccode{size(source\_positions,1)}.}

\zeffield{acceptable\_source\_depth}{1,1}{double}{mustBeNonnegative}{Peel
depth (millimetres in the interpolation helpers) so sources are not placed
on the outermost layer of active tissue.}

\zeffield{location\_unit}{1,1}{double}{}{\(1\) millimetres, \(2\) centimetres,
\(3\) metres (Mesh tool dropdown \ccode{mm}/\ccode{cm}/\ccode{m} in
\ccode{zef\_mesh\_tool}). After FEM (metres), \ccode{zef\_lead\_field\_matrix}
scales \ccode{source\_positions} by \(1000\), \(100\), or \(1\). Interpolation
searches against \ccode{nodes} in millimetres.}

\zeffield{location\_unit\_current}{1,1}{double}{}{Unit currently stored on
\ccode{source\_positions} during interpolation.}

\zeffield{preconditioner}{1,1}{double}{}{CPU PCG preconditioner for the
electrode-transfer solve: \(1\) incomplete Cholesky
(\ccode{ichol} with type \ccode{nofill}), \(2\) SSOR. Default in
\ccode{zef\_init} is \(2\). EEG and TES call
\ccode{zef\_transfer\_matrix}; MEG and EIT inline the same loops.
On GPU the field is ignored and the iteration uses Jacobi
(\(1./\mathrm{diag}(A)\)).}

\zeffield{preconditioner\_tolerance}{1,1}{double}{}{Copied to
\ccode{lf\_param.cholinc\_tol}. The live PCG does not read it:
incomplete Cholesky is no-fill, with no drop-tolerance argument.}

\zeffield{solver\_tolerance}{1,1}{double}{}{Relative residual for
\ccode{zef\_transfer\_matrix} PCG (default \(10^{-6}\)). A column that
fails this tolerance aborts and returns an empty transfer.}

\zeffield{lead\_field\_filter\_quantile}{1,1}{double}{mustBeInRange(0,1)}{%
Quantile of column \(2\)-norms kept by \ccode{zef\_lead\_field\_filter}.
\(1\) keeps every column; \(0\) would drop all.}

\zeffield{source\_interpolation\_on}{1,1}{logical}{}{If true, wrappers call
\ccode{zef\_source\_interpolation} so inverse
\ccode{zef\_processLeadfields} can subset columns.}

NSE (\ccode{src/forward/nse}) and GPU-ToRRe wave
(\ccode{src/forward/wave}) are separate forward models; they do not write
EEG/MEG \ccode{zef.L}.
