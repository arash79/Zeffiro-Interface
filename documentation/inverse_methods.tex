\section{Inverse methods}\label{sec:inverse_methods.tex}

Given measurements \(y\) (sensors \(\times\) time) and a lead field \(L\),
Zeffiro reconstructs a source vector \(x\) such that \(Lx \approx y\). The
result is stored as \ccode{zef.reconstruction} (a cell, one vector per time
frame) and a small metadata struct \ccode{zef.reconstruction\_information}.

There are two live tracks. They share \(L\) and \(y\) but not the solver
code.

\begin{itemize}
\item \textbf{Inverse tools menus.} Rows of
      \ccode{profile/<name>/zeffiro\_plugins.ini} open the legacy plugins
      under \ccode{tools/plugins} (\ccode{zef\_CSM\_iteration},
      \ccode{zef\_KF}, \ccode{zef\_ias\_iteration}, \ldots).
\item \textbf{Class / cluster.} \ccode{zef\_inverse\_run} looks up an id in
      \ccode{utilities.cluster.inverse\_method\_registry}, then
      \ccode{utilities.inverse.run\_frame\_loop} calls
      \ccode{inverse.*Inverter} in the \ccode{+inverse} package.
\end{itemize}

No default-profile Inverse-tools button constructs an
\ccode{inverse.*Inverter}. Example of the class path:

\begin{lstlisting}[style=unnumberedlines, language=Matlab]
[zef, r] = zef_inverse_run(zef, "eloreta", "execution", "local");
[zef, r] = zef_inverse_run(zef, "sloreta", "execution", "local", ...
    "MethodParams", struct("method_type", "sLORETA"));
\end{lstlisting}

Registry ids select a \emph{class}. Variants such as sLORETA versus dSPM are
properties (\ccode{method\_type}), not separate ids. Ids \ccode{mne} and
\ccode{wmne} both select \ccode{inverse.MNEInverter} (always weighted by
\ccode{theta}).

\subsection{eLORETA (class \texttt{inverse.ELORETAInverter})}

Let \(L \in \mathbb{R}^{n_e \times n_s}\) denote the lead field. The
eLORETA inverse operator is formed as
\begin{equation}
T = W^{-1} L^\top (L W^{-1} L^\top + \alpha H)^{-1},
\end{equation}
where \(\alpha > 0\) is \ccode{regularization\_parameter} and
\(H = I - \frac{1}{n_e}\mathbf{1}\mathbf{1}^\top\) if
\ccode{apply\_average\_reference} is true, otherwise \(H = I\).

The implementation iterates \(W^{-1}\). For each free-orientation source
block \(i\) with columns \(L_i\),
\begin{equation}
A_i = L_i^\top M^{-1} L_i, \qquad
M = L W^{-1} L^\top + \alpha H,
\end{equation}
and the block of \(W^{-1}\) is the inverse square root of \(A_i\)
(eigendecomposition, eigenvalues floored). Fixed-orientation sources
(\ccode{procFile.s\_ind\_4}) use a scalar \(1/\sqrt{L_{i1}^\top M^{-1} L_{i1}}\)
times \(I_3\).

If \(\alpha\) is empty at \ccode{initialize},
\begin{equation}
\alpha = \frac{\mathrm{trace}(L L^\top)}{n_e \cdot 10^{\mathrm{SNR}/10}}.
\end{equation}

\ccode{precompute} caches \(T\). \ccode{invert} applies \(z = Tf\) for one
frame (optional GPU). The GUI eLORETA path, if present, is a plugin; the
default head profile Inverse tools list does not include a class-eLORETA
button.

References: Pascual-Marqui (2007), \texttt{arXiv:0710.3341}; Pascual-Marqui
(2011), \emph{Philosophical Transactions of the Royal Society A}, 369(1952),
3768--3784.
