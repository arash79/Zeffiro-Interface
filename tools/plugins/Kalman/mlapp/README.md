# Kalman — App Designer layout

`zef_kf_app.mlapp` is the window **ZEFFIRO Interface: Kalman Filter**. `m/zef_kf_open_window.m` constructs `zef.KF = zef_kf_app` and sets **StartButton** to `zef = zef_KF(zef)`. **ApplyButton** copies widgets onto `zef` without inverting.

Do not run the generated app from the command line. Solver, DTI `Q`, and menu path: parent [../README.md](../README.md).
