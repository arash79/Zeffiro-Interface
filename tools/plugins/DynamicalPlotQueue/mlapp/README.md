# Dynamical plot queue — App Designer layout

`zeffiro_interface_dynamical_plot_queue_app.mlapp` is the window source. The INI callback is the **MATLAB file** `m/zeffiro_interface_dynamical_plot_queue.m` (in-file function `zef_dpq_start`), which opens this app through `zef_dpq_window` and wires **Add** / **List** / **Delete** menus there. Do not treat the `.mlapp` as the menu callback.

User manual: [../README.md](../README.md). MATLAB files: [../m/README.md](../m/README.md).
