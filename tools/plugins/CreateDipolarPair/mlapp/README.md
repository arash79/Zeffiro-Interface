# Create dipolar pair — App Designer layout

`zeffiro_interface_create_dipolar_pair.mlapp` is the window source. The start script `m/zef_create_dipolar_pair_start.m` calls `zeffiro_interface_create_dipolar_pair` (the app MATLAB compiles from this file), then assigns **Add** / **Plot** `buttonpushedfcn`. Do not run the generated app from the command line; it will not wire those callbacks.
