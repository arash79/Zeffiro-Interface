# JL GMM app — App Designer layouts

INI callback `GMModelApp_start` lives under `m/BasicGMM/`. These `.mlapp` files are that window and its option/export/plot dialogs:

| File | Role |
|------|------|
| `GMModelApp.mlapp` | Main clustering window |
| `GMM_ModelingOpt.mlapp` | Modelling options (advanced on → `zef_AdvGMModeling`) |
| `GMM_PlotOpt.mlapp` | Plot options |
| `GMMExport.mlapp` | Export |

Not an inverse solver. Plugin manual: [../../README.md](../../README.md). This JL app folder: [../README.md](../README.md).
