# +utilities/+fs2zef/data

## Folder purpose

Static **templates** for FreeSurfer→Zeffiro conversion examples: electrode layout and a segmentation import skeleton. Production per-subject manifests are generated by `run`, not stored here as the sole source of truth.

## Main contents

| File | Role |
|------|------|
| `electrodes.dat` | Sample electrode table |
| `import_segmentation_template.zef` | Template import manifest |

## Code functionality

Data only — copied or referenced by examples / generators. No MATLAB entry point in this folder.

## Workflow context

Supports `fs2zef` demos. Runtime shipped anatomy for the default head demo also lives under `data/segmentations/multicompartment_head_project/`.

## Usage instructions

Use as copy sources when authoring a new subject pipeline; prefer generated outputs from `utilities.fs2zef.run` for real subjects.

## Important notes

- Not automatically loaded at Zeffiro startup.
- Keep formats compatible with `core.io.electrodes` / import parsers.

## Developer guidance

- Do not overwrite templates with patient data.
- Pitfall: pointing `import_to_new_project` at this template expecting a full mesh+LF project.
