# Brainstorm converter — `projects/`

Intended dump directory for generated Brainstorm-plugin Zeffiro projects. The tree currently contains only `README.txt` (no sample `.mat`).

`utilities.brainstorm2zef.run` saves wherever `config.project_file_name` points. Intermediate `*_surface_meshes.mat` files are written **beside the settings file**, not automatically into this folder. Parent: [../README.md](../README.md).
